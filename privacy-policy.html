개인정보처리방침

노래 길이 작업 실행기 · 시행일: 2026년 9월 7일

노래 길이 작업 실행기(이하 "확장 프로그램")는 사용자의 개인정보를 최소한으로 처리하며, 사용자가 입력한 설정을 주로 사용자의 기기에 저장합니다.

1. 수집 및 저장하는 정보

확장 프로그램은 다음 정보를 사용자의 Chrome 로컬 저장소에 저장합니다.

  • YouTube Data API 검색에 사용하는 API Key
  • Soop 응원봉 이모티콘 문자열

채팅 메시지 내용, 계정 비밀번호, 결제 정보, 연락처, 방문 기록, 광고 식별자는 수집하거나 저장하지 않습니다.

2. 정보 이용 목적

  • 사용자가 요청한 YouTube 노래 검색 및 재생 시간 조회
  • 사용자가 설정한 Soop 응원봉 자동 전송 기능 제공
  • 사용자 설정의 다음 방문 시 재사용

3. 외부 서비스 및 전송

노래 검색을 수행할 때 사용자가 제공한 API Key와 검색어가 YouTube Data API로 전송됩니다. YouTube의 정보 처리에는 Google 개인정보처리방침이 적용됩니다.

확장 프로그램은 사용자의 채팅 메시지 내용을 외부 서버로 전송하지 않습니다. Soop 페이지의 DOM을 제어해 사용자가 선택한 기능을 수행할 뿐입니다.

4. 보관 및 삭제

저장된 설정은 Chrome의 확장 프로그램 저장소에 보관됩니다. 사용자는 Chrome 확장 프로그램을 삭제하거나 브라우저의 확장 프로그램 저장 데이터를 삭제해 저장된 정보를 제거할 수 있습니다.

5. 권한 사용

  • storage: API Key와 사용자 설정을 로컬에 저장합니다.
  • activeTab: 사용자가 현재 연 Soop 탭의 상태를 확인하고 기능을 실행합니다.
  • host permissions: Soop 페이지에 제어 패널과 관련 기능을 제공하고 YouTube Data API를 호출합니다.

6. 아동의 개인정보

확장 프로그램은 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 고의로 수집하지 않습니다.

7. 방침 변경

기능이나 관련 법령의 변경에 따라 본 방침을 수정할 수 있습니다. 변경 사항은 이 페이지에 게시하고 시행일을 갱신합니다.

8. 문의

개인정보 처리와 관련한 문의는 Chrome Web Store에 등록된 개발자 연락처를 이용해 주세요.

# 나만의 SOOP 확프

Soop(숲) 생방송 페이지에 제어 패널을 삽입하고, 검색한 노래의 길이 동안 채팅 이모티콘을 자동 전송하는 Chrome 확장 프로그램입니다. 그 외에도 자동 재생 끄기, 방송하기 버튼 숨기기, 등록한 스트리머의 라이브 자동 감시·오픈 기능을 제공하며, 모든 기능은 확장 프로그램 설정 페이지에서 켜고 끌 수 있습니다.

## 기능

1. **노래 검색 & 응원봉 자동 전송**: YouTube Data API로 노래와 재생 시간을 검색하고, 그 길이 동안 지정한 Soop 채팅 이모티콘을 반복 전송합니다.
2. **자동 재생 끄기**: 생방송 종료 후 표시되는 자동 재생 버튼을 감지해 자동으로 끕니다.
3. **방송하기 버튼 숨기기**: Soop 페이지의 방송하기 버튼을 화면에서 숨깁니다.
4. **라이브 자동 감시·오픈**: 등록한 스트리머가 방송을 시작하면 확인 없이 백그라운드 탭으로 자동으로 엽니다. 재생이 멈추면 라이브 상태를 재확인해 새로고침하거나, 방송 종료로 확인되면 카운트다운 후 탭을 자동으로 닫습니다(취소 가능).
5. **페이지 패널**: 팝업을 닫아도 유지되는 시작·중지·진행 상태 UI를 Soop 페이지 우측에 표시합니다.
6. **오늘의 포인트 현황**: Soop 페이지 한쪽 구석의 작은 패널로, mypoint 상세내역 페이지에 가지 않아도 오늘 어떤 활동의 포인트가 부족한지 카테고리·세부 항목별로 바로 확인할 수 있습니다.
7. **VOD 파일별 상세 정보 + 다운로드 + 유튜브 업로드 도우미**: VOD 재생 페이지에서 해당 VOD를 구성하는 파일별로 VOD URL·방송 당시 시작·종료 시각·채팅 로그 URL을 보여주고, 파일별로 바로 다운로드하거나, 이 정보로 제목/설명을 미리 채워 YouTube Studio 업로드 창을 열어줍니다.
8. **설정 페이지**: 확장 프로그램 아이콘 클릭 시 열리는 설정 페이지에서 위 기능들을 개별적으로 켜고 끄고, 관련 값을 설정할 수 있습니다.

## 설치 방법

1. Chrome 브라우저에서 `chrome://extensions/` 접속
2. 우측 상단의 "개발자 모드" 활성화
3. "압축해제된 확장 프로그램을 로드합니다" 클릭
4. 이 프로젝트 폴더 선택
5. `https://play.sooplive.com` 생방송 페이지를 새로고침

## 사용 방법

### 설정 페이지

1. Chrome 툴바의 확장 프로그램 아이콘 클릭 → 설정 페이지가 열립니다.
2. **응원봉 자동 전송**: YouTube API Key, 이모티콘 문자열, 전송 개수·간격을 입력하고 기능을 켭니다.
3. **자동 재생 끄기 / 방송하기 버튼 숨기기**: 토글로 각각 켜고 끕니다.
4. **라이브 자동 열기**: 기능을 켜고, 감시 주기(분)와 방송 종료 후 탭 자동 닫기까지의 시간(초)을 설정한 뒤, 감시할 스트리머 ID를 추가합니다. 등록된 스트리머는 개별적으로 켜고 끄거나 삭제할 수 있습니다.
5. **오늘의 포인트 현황**: 토글로 켜고 끕니다. 별도 설정 없이 현재 Soop에 로그인된 계정 기준으로 자동 조회됩니다.
6. **VOD 파일별 상세 정보**: 토글로 켜고 끕니다. 별도 설정 없이 VOD 재생 페이지에서 자동으로 조회됩니다.

### 응원봉 자동 전송 (Soop 페이지 패널)

1. `play.sooplive.com` 생방송 페이지 오른쪽 위에 표시되는 제어 패널에서 YouTube API Key 입력
2. 노래 제목 또는 아티스트명 검색
3. 이모티콘 문자열과 전송 개수·간격 설정
4. "작업 시작" 버튼 클릭
5. 노래 길이 동안 Soop 채팅창에 이모티콘이 자동 전송됩니다
6. 중지하려면 페이지 패널의 "중지" 버튼 클릭

자동 전송은 Soop 탭의 content script에서 실행됩니다. 채팅 입력창에 글자가 있거나 지정한 이모티콘 버튼을 찾을 수 없으면 입력 내용을 보호하기 위해 자동 전송을 중지합니다.

### 라이브 자동 감시·오픈

설정 페이지에서 등록한 스트리머 ID를 설정한 주기마다 백그라운드에서 조회합니다. 방송이 시작된 것이 확인되면 해당 스트리머의 생방송 탭을 백그라운드로 새로 엽니다(재생 시작을 위해 잠깐 포커스했다가 원래 탭으로 되돌립니다). 탭에서 영상 재생이 멈추면 라이브 상태를 재확인하여, 방송이 계속 진행 중이면 페이지를 새로고침하고, 방송이 종료된 것이 확인되면 설정한 시간(기본 5초) 후 탭을 자동으로 닫는 카운트다운을 표시합니다. 카운트다운 중 "닫지 않기"를 누르면 자동 닫기를 취소할 수 있습니다. 이 기능은 백그라운드가 자동으로 연 감시용 탭에서만 동작하며, 사용자가 직접 연 탭에는 영향을 주지 않습니다.

### 오늘의 포인트 현황

`www.sooplive.com`, `play.sooplive.com`, `vod.sooplive.com` 페이지 우측 하단에 작은 패널이 표시됩니다. 기본적으로 접힌 상태이며 클릭하면 펼쳐지면서 현재 로그인 계정의 오늘자 포인트 미션 현황(LIVE/VOD/방송국/기타 카테고리별 획득 포인트와 세부 활동별 달성 여부)을 불러옵니다. 아직 완료하지 않은 활동이 목록 위쪽에 강조되어 표시되며, 패널의 새로고침(⟳) 버튼으로 다시 조회할 수 있습니다.

### VOD 파일별 상세 정보

`vod.sooplive.com/player/{titleNo}` 형태의 VOD 재생 페이지 좌측 하단에 작은 패널이 표시됩니다. 해당 VOD의 각 파일마다 ①VOD 페이지 URL, ②방송 당시 실제 시작·종료 시각(예: `2026-09-16 20:15:32 ~ 2026-09-16 20:45:10`)과 길이, ③그 파일 구간의 채팅 로그 XML URL을 보여주며, 파일별 "복사" 버튼이나 "전체 복사" 버튼으로 이 세 가지가 정리된 텍스트를 클립보드에 복사할 수 있습니다. VOD를 파일 단위로 다운로드해 유튜브에 나눠 올릴 때, 각 영상 설명란에 붙여넣는 용도로 쓰기 위한 기능입니다.

각 파일 항목의 "다운로드" 버튼을 누르면 Soop의 다운로드 인증 API로 실제 mp4 다운로드 주소를 받아와 크롬 다운로드 목록에 바로 내려받습니다(로그인 계정 기준, 파일별 화질은 Soop이 제공하는 것 중 첫 번째를 사용).

각 파일 항목의 "유튜브에 업로드" 버튼을 누르면 YouTube Studio 업로드 창(`youtube.com/upload`)이 새 탭으로 열리고, 제목(`[방송 날짜 (파일 순서/전체)] 원본 방송 제목`)·설명(위 3가지 정보)이 이 탭에 맡겨집니다. Studio 업로드 창이 열리면 제목/설명 입력칸이 자동으로 채워지고, 설정 페이지(VOD 파일별 상세 정보 카드)에 저장해둔 옵션 — **"아동용이 아닙니다" 선택, 추가할 재생목록(여러 개 가능, Studio에 보이는 이름과 정확히 일치해야 함), 공개 범위(비공개/일부 공개/공개)** — 도 자동으로 적용됩니다. 마지막 "저장"은 업로드가 끝난 뒤 직접 누르며, 배너에 단계별 성공/실패(✓/✗)가 표시됩니다.

**mp4 파일 자동 첨부**: 배너의 "다운로드 폴더 연결" 버튼으로 파일이 저장되는 폴더를 한 번 허용해두면(브라우저를 다시 켠 뒤에는 "폴더 접근 허용"을 한 번 더 눌러야 할 수 있습니다), 그 폴더에서 해당 파일을 찾아 Studio 업로드 창에 자동으로 첨부합니다. 이 확장의 "다운로드" 버튼으로 받은 파일은 실제 저장된 이름(특수문자 치환, 중복 시 `(1)` 접미사)을 기록해두고 그 이름으로 찾으며, 기록이 없으면 Soop이 알려준 원래 파일명으로 찾습니다. 다운로드가 완전히 끝난 뒤에 업로드 버튼을 눌러야 하고, 파일을 못 찾거나 Studio가 반응하지 않으면 mp4를 직접 선택하면 됩니다. 설정 페이지의 "다운로드 하위 폴더"에 이름(예: `SOOP-VOD`)을 적으면 다운로드가 Chrome 다운로드 폴더 안의 그 하위 폴더로 저장되며(상위 폴더를 연결해도 하위 폴더까지 찾아줍니다), 비워두면 다운로드 폴더에 바로 저장됩니다. Chrome은 OS 기본 다운로드 폴더 자체를 폴더 선택창에서 막기 때문에, 기본 위치를 쓴다면 하위 폴더를 지정하는 것이 안전합니다. 자동 입력이 안 되는 경우를 대비해 화면 왼쪽 아래 배너에 "제목 복사"/"설명 복사" 버튼이 있습니다. Studio 화면 구조에 기대는 방식이라 유튜브가 UI를 바꾸면 `src/youtubeStudio.js`의 셀렉터를 손봐야 할 수 있습니다.

## 파일 구조

- `manifest.json`: Chrome 확장 프로그램 설정
- `src/background.js`: 백그라운드 서비스 워커 (설정 관리, 라이브 감시 알람, 탭 관리, 파일 다운로드, Studio 업로드 탭 관리)
- `src/soopLiveApi.js`: Soop API 호출 모듈 - 라이브 방송 상태, 로그인 정보, 포인트 미션 현황, VOD 파일 정보 조회 (background에서 사용)
- `src/content.js`: Soop 페이지 패널과 응원봉 자동 전송 로직
- `src/songSearch.js`: YouTube 노래 검색 및 길이 조회 모듈
- `src/disableAutoPlay.js`: 생방송 종료 후 자동 재생 끄기 로직
- `src/hideBroadcastButton.js`: 방송하기 버튼 숨기기 로직
- `src/liveMonitor.js`: 백그라운드가 자동으로 연 감시 탭에서 재생 상태를 감시하고 자동 새로고침·자동 닫기를 수행하는 content script
- `src/pointStatus.js`: 오늘의 포인트 현황 패널을 표시하는 content script
- `src/vodFileInfo.js`: VOD 재생 페이지에서 파일별 상세 정보 패널을 표시하는 content script
- `src/youtubeStudio.js`: YouTube Studio 업로드 창에서 VOD 제목/설명을 자동 입력하는 content script
- `src/options.html`, `src/options.js`, `src/options.css`: 확장 프로그램 설정 페이지
- `src/popup.html`, `src/popup.js`, `src/styles.css`, `src/soopHandler.js`, `src/taskRunner.js`, `src/dummy.js`: 이전 팝업 기반 구현에서 사용하던 파일 (현재 manifest에 연결되어 있지 않음, 미사용)

## 응원봉 전송 설정

- 이모티콘 문자열: `/응원봉2/`처럼 슬래시로 감싼 Soop 이모티콘 문자열
- 한 번에 보낼 개수: 1~20개
- 전송 간격: 최소 1초 이상, 최소 간격부터 최대 간격까지 무작위
- 실행 시간: 검색한 YouTube 노래의 길이

## YouTube API Key

[Google Cloud Console](https://console.cloud.google.com/)에서 YouTube Data API v3를 활성화하고 API Key를 발급한 뒤 설정 페이지 또는 Soop 페이지 패널에 저장합니다.
